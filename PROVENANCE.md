# Provenance

## Moscow and Yaroslavl

The lists of Stations for Moscow (`moskva`) and Yaroslavl (`yaroslavl`) come from the site <https://vcfm.ru/>.
The author of the site gave the owner of this project written permission to use the data of the site.
The author replied by e-mail on 2026-10-16. The reply, in the original Russian:

> Добрый день, используйте со ссылкой.

English translation: "Good afternoon, use it with a link."

The permission says "use with a link". It does not mention a license. Each Region file keeps a `source` with a link to the site.
The author is not named here on purpose. The owner keeps the original e-mail locally.

## New data

Every new Region needs a `source` and the contributor's confirmation in the PR that the source allows this use.
